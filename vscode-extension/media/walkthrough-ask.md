# Ask SYNAPSEED

Use natural language to ask about your codebase:

- *"Why is the build broken?"*
- *"Run a security audit"*
- *"Explain the router module"*
- *"What changed recently?"*

SYNAPSEED automatically orchestrates the right subsystems — AST analysis, search, git history, diagnostics, and security scanning — to produce a comprehensive answer.

**Shortcut:** `Cmd+Shift+A` (macOS) / `Ctrl+Shift+A` (Linux/Windows)
