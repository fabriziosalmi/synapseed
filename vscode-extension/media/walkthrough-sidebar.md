# Explore the Sidebar

The SYNAPSEED activity bar contains **9 views**:

| View | What it shows |
|------|---------------|
| **Project Status** | Build system, git status, active plugins |
| **Metrics** | File count, dependencies, consistency score |
| **Diagnostics** | Compiler errors/warnings → Problems panel |
| **Architecture** | Dependency graph, coupling, cycle detection |
| **Git History** | Recent commit intents (feature, fix, refactor) |
| **Security** | DLP secrets scan, command safety, scan status |
| **Consistency** | Documentation drift, oracle fixes |
| **Janitor** | Clippy warnings, unused deps, fix proposals |
| **Telemetry** | OTLP spans, hot endpoints, slow functions |

Click the **refresh** icon in each view title to update data.
