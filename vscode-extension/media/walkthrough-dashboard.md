# Dashboard

The interactive dashboard gives you a visual overview:

- **Grade card** — Architecture health grade (A–F)
- **Score card** — Numeric architecture score
- **Build status** — Build system detection
- **Module count** — Modules in the project
- **Dependency count** — Project dependencies
- **Violations** — Architecture rule violations

Plus:
- **Module instability chart** — Horizontal bar chart
- **Recent commit intents** — Feature, fix, refactor, chore
- **Recommendations** — Actionable improvement suggestions

Click **Refresh** to reload all data live.
